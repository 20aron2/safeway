# 안심길 (SafeWay)

공공데이터(CCTV·안전비상벨)를 이용해 야간 도보 경로를 비교하는 웹 앱이에요.
「인공지능과 디지털 사고」 팀 프로젝트 · 데이터 범위: 부산광역시 16개 구·군

> 이 앱은 실제 안전을 보장하지 않아요. 공공데이터에 등록된 시설 위치를 참고해 경로를 비교할 뿐이에요.

## 실행 방법 (Windows)

명령 프롬프트에서:

```
cd Documents\safeway
.venv\Scripts\activate
pip install -r requirements-dev.txt
streamlit run app.py
```

브라우저가 자동으로 열려요 (안 열리면 http://localhost:8501).
끝낼 때는 명령 프롬프트에서 `Ctrl + C`.

두 번째부터는 `pip install`은 건너뛰고 `activate` → `streamlit run app.py`만 하면 돼요.

## 테스트 방법

```
python -m pytest
```

거리 계산, 시설 개수 세기, 중복 제거, 추천 점수, 설명 문장을 자동으로 확인해요. 코드를 고친 뒤에는 꼭 한 번 돌려 보세요.

## 지금 상태

| 기능 | 상태 |
|---|---|
| 출발지·도착지 지정: 장소 이름 검색(TMAP), 📍 현재 위치, 지도 클릭 | 동작 |
| 지도 위 내 위치 버튼 (실시간 파란 점, 브라우저 안에서만 처리) | 동작 |
| 지도 선택: TMAP 웹 지도(기본) ↔ 브이월드 | TMAP 지도는 실제 화면 확인 필요 |
| 경로 후보 2~3개 표시, 중복 경로 제거 | TMAP 키가 있으면 **실제 도보 경로**, 없으면 가상 직선 경로 |
| CCTV·비상벨·보안등 표시와 반경 안 개수 세기 | **실제 공공데이터** (부산 CCTV 11,186곳, 비상벨 651곳, 보안등 66,142곳) |
| 데이터 범위 경고 (경로가 데이터 없는 지역을 지나면 카드에 표시) | 동작 |
| 1km당 시설 수, 시설 없는 최장 구간 (100m 이상 구간은 지도에 빨간 점선) | 동작 |
| 지구대·파출소 위치 (TMAP 장소 검색, 참고용) | 동작 |
| 경로 공유 링크, 야간 지도(19~6시 자동) | 동작 |
| 추천 기준 3가지, 점수 공식 공개 | 동작 |
| 설명 문장 | Gemini 키가 있으면 AI 설명 (Python이 계산한 숫자만 쓰는지 자동 확인), 없거나 실패하면 Python 기본 설명 |

화면 상단 배너에 데이터 출처가 항상 표시돼요. 가상 데이터가 섞이면 노란색 '데모 모드', 모두 실제 데이터면 초록색 '실제 데이터 모드'예요.

## 공공데이터 다시 정리하기

새 CSV를 받으면 `data/raw` 폴더 아무 곳에나 넣은 뒤 (파일 이름은 상관없어요. 열 이름을 보고 CCTV·비상벨·보안등을 알아서 구분해요):

```
python scripts/build_facilities.py
```

정리 과정은 `data/processed/cleaning_report.md`에 기록돼요.

## API 키 넣는 법

`.streamlit/secrets.toml.example`을 복사해 `secrets.toml`로 이름을 바꾸고 키를 넣어요.
이 파일은 `.gitignore`에 있어서 GitHub에 올라가지 않아요.
